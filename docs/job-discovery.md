# 公开职位发现

## 当前支持的来源

- 腾讯招聘公开 API：在本地工作台点击“更新腾讯公开职位”后读取公开岗位数据。
- 手动 JSON 导入：服务端提供 `POST /api/jobs/import`，只接收公开岗位内容，适用于未来的公开 URL/JD 解析或用户自有导入工具。

OfferBiu 仍只使用其公开页面探针。只有页面实际暴露可用岗位记录时，才会作为自动来源加入；当前探针无法取得可用职位数据时，应用不会猜测、补造或绕过访问限制。

## 数据保存与去重

职位与来源链接保存在本地 SQLite 数据目录中：默认 Windows 路径为 `%LOCALAPPDATA%\CampusJobAgent`，可通过 `CAMPUS_JOB_AGENT_DATA_DIR` 覆盖。每次更新会保留来源、来源岗位 ID、公开 URL 和抓取时间；相同公司、职位、地点与 JD 指纹的记录会合并，并保留来源链接。

不保存登录状态、Cookie、认证头、简历内容或外部招聘网站凭据。一次来源访问失败只更新来源状态，不会把已有岗位误标为过期。

## 手动导入 JSON

请求体格式如下；`postedAt` 可省略，时间使用 ISO 8601：

```json
{
  "jobs": [{
    "source": "manual",
    "sourceJobId": "public-url-identifier",
    "sourceUrl": "https://careers.example.com/jobs/123",
    "title": "前端开发实习生",
    "company": "示例科技",
    "location": "上海",
    "description": "来自公开 JD 的岗位说明。",
    "capturedAt": "2026-07-17T10:00:00.000Z"
  }]
}
```

导入接口和公开来源刷新都是本地网页发起的变更请求，必须来自已配置的 `127.0.0.1` 页面来源。

## 手动投递边界

本功能只帮助发现、保存和查看公开职位。打开“查看公开职位原页”只是普通链接；应用不会自动打开招聘页面、登录、填写表单或提交申请。最终投递始终由用户自行完成。
