# 自建公司岗位库

## 初次使用

启动应用后，在“自建公司岗位库”中点击“导入内置芯片公司”。种子包含 20 家经过人工审阅的半导体相关公司；重复导入只更新记录，不会产生重复公司。

也可以提交公司名称与公开官网。手动记录先进入候选区，并立即走与自动发现相同的验证流程。证据不足的记录会隔离并按退避时间重试，不能绕过验证直接进入正式公司库。

## 可选公司发现

在服务端环境变量中设置 `BRAVE_SEARCH_API_KEY` 后，“发现新公司”会使用预设芯片行业查询。密钥只放在请求头中，不写入数据库、日志或网页响应。未配置时只禁用这一项网络能力；种子导入、手动添加和岗位同步仍可使用。

发现请求限制为每秒一次、最多两页。遇到限流时 API 返回可重试错误，候选记录仍保留在本机。

## 招聘入口与岗位同步

招聘入口必须属于已核验公司，并由该公司的公开官网实际链接。外部 ATS 只有在官网提供明确链接时才接受。来源优先级为结构化 JSON-LD、明确 JSON 映射、固定 HTML 规则；没有安全适配器的来源会跳过，等待后续支持。

点击“更新官方岗位”会顺序同步到本机岗位库。每个来源独立记录健康度、最近成功/失败、退避和下次同步时间。后台维护任务每小时检查一次到期候选和来源，并防止任务重叠。

## 数据和操作边界

- 默认数据目录：`%LOCALAPPDATA%\CampusJobAgent`
- 覆盖目录：`CAMPUS_JOB_AGENT_DATA_DIR`
- 公司、候选、来源、岗位和生命周期都保存在本机 SQLite。
- 只处理公开网站，不读取或保存登录会话。
- 不自动投递。岗位详情只提供普通官网链接，申请由用户手动完成。
